# Assignment 2 – Express Portfolio Website

## Project Description
This project is a personal portfolio website developed for INFR3120 Assignment 2 using Node.js, Express.js, and EJS.

## Technologies Used
- Node.js
- Express.js
- EJS
- Bootstrap
- Font Awesome
- HTML

## Website Pages
1. Home
2. About
3. Projects
4. Contact

## Installation
1. Clone the GitHub repository.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:3000 in your browser.

## Development
The project was generated using Express Generator with EJS as the template engine.
